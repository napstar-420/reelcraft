---
title: Glossary
description: Short definitions of the words used in Reelcraft and in this guide.
---

**Approval** (human approval): a pause after a stage, so you can accept or reject its output. See
[Iterate, conditions and approval](../blueprints/iterate-conditions-approval.md#human-approval).

**Artifact**: an output a stage made, stored with the run. Text, data, images, video, audio, subtitles and
timelines are all artifacts.

**Asset**: an image, video or audio file you uploaded to a channel to reuse. See
[Assets](../channels/assets.md).

**Attempt**: one try by a stage. A stage can make several. See
[Attempts](../runs/run-page.md#attempts).

**Binding**: the connection that tells a slot or context entry where its value comes from. See
[Connecting stages](../blueprints/connecting-stages.md).

**Blueprint**: a recipe for a video: an ordered list of stages. See
[Blueprints](../blueprints/blueprints.md).

**Budget cap**: the most a run may spend. See [Budget and costs](../runs/budget-and-costs.md).

**Canvas**: the blueprint editor. Also, the size of a timeline's picture.

**Capability**: the technical name for a stage's type, shown as **Capability** in the inspector. See
[Stage types](../stage-types/index.md).

**Channel**: the home for one kind of video, with its blueprints, characters, assets and runs. See
[Channels](../channels/channels.md).

**Character**: someone who appears in your videos, with reference images so they look the same every time.
See [Characters](../channels/characters.md).

**Check**: an automatic pass-or-fail test on a stage's output. See [Checks](../blueprints/checks.md).

**Context**: extra values you give a stage, to use in its prompt. See
[Connecting stages](../blueprints/connecting-stages.md#slots-and-context).

**Defaults**: models, retries, caps and format set once for a channel or blueprint. See
[Defaults](../channels/defaults.md).

**Dry run**: a free practice run using placeholder results. See [Dry runs](../runs/dry-runs.md).

**Final video**: the video made by the last stage that produced one. See
[Outputs and downloads](../runs/outputs-and-downloads.md#the-final-video).

**Input**: something a run asks you for when it starts. See
[Blueprint settings](../blueprints/settings.md#inputs).

**Iterate**: repeating a stage once for each item in a list. See
[Iterate](../blueprints/iterate-conditions-approval.md#iterate).

**Judge**: the AI model that scores an output in quality control. See
[Quality control](../blueprints/quality-control.md).

**Memory**: values stages save during a run, for later stages to read. See
[Connecting stages](../blueprints/connecting-stages.md#memory).

**Model**: the AI behind a stage, picked from a provider. See [Models](../blueprints/models.md).

**Output**: what a stage makes. See [Outputs](../blueprints/outputs.md).

**Path**: a way to pick one field out of a structured value, such as `scenes` or `scene.narration`.

**Prompt**: the instructions sent to an AI model. See [Prompts](../blueprints/prompts.md).

**Provider**: a company or service that supplies models, such as OpenRouter or ElevenLabs. See
[Models](../blueprints/models.md#providers).

**Quality control (QC)**: scoring an output with an AI judge. See
[Quality control](../blueprints/quality-control.md).

**Reference images**: pictures of a character that are sent to the model. See
[Characters](../channels/characters.md).

**Role**: a named place in a blueprint for one of the channel's characters. See
[Blueprint settings](../blueprints/settings.md#role).

**Run**: one go at making a video. See [Starting a run](../runs/starting-a-run.md).

**Schema**: a description of the fields a `data` output must have. See [Outputs](../blueprints/outputs.md).

**Slot**: an input a stage type asks for, such as `text` for Generate Speech. See
[Connecting stages](../blueprints/connecting-stages.md).

**Stage**: one step of a blueprint. See [Stages](../blueprints/stages.md).

**Stage cap**: the most one stage may spend in a run. See
[Budget and costs](../runs/budget-and-costs.md).

**Style**: how text or captions look in a timeline. See [Timelines](../video/timelines.md#text-and-styles).

**Timeline**: a plan for a video: tracks of clips, audio, text and captions. See
[Timelines](../video/timelines.md).

**Track**: one layer of a timeline.

**Version**: a saved, unchangeable copy of a blueprint, such as `v1.3`. See
[Versions](../blueprints/versions.md).
